# Flexbox Crash Course Project

A responsive web page built with **semantic HTML5** and **CSS Flexbox**, based on the Flexbox Crash Course project.

## 🚀 Live Demo

Check out the live project here:  
👉 [https://arbishtehseen.github.io/FLEXBOX-PROJECT/](https://arbishtehseen.github.io/FLEXBOX-PROJECT/)

---

## 🛠️ Tech Stack

* **HTML5** (Semantic layout structure)
* **CSS3** (Flexbox, custom styling, media queries)

---

## ✨ Features

* **Semantic HTML Structure:** Clean layout using `<nav>`, `<header>`, and `<section>` tags.
* **Flexbox Alignment:** Multi-column layouts using `justify-content: space-between`, `align-items: center`, and `flex: 1`.
* **Fully Responsive:** Mobile-friendly view with CSS media queries (`@media (max-width: 768px)`).
* **Modern UI:** Clean typography, card shadows, and smooth hover effects.
